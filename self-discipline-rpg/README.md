# 自律RPG 🎮

把「自律」玩成一场升级冒险的游戏化待办工具 —— **重要紧急四象限 × 段位养成**。

纯前端单页应用，零依赖、无后端、双击即用。所有数据保存在浏览器 `localStorage`，刷新不丢失。

> 深色主题 + 霓虹渐变 · 移动端优先 · 离线完整可用

---

## ✨ 特性总览

- 🗂️ **四象限看板**：任务按「重要 × 紧急」自动归类到四个象限，2×2 网格展示
- 🗂️ **三类任务**：日常习惯 / 固定日程 / 一次性目标，支持增删改、备注、完成
- ⭐ **重点任务**：每天标记 3 个重点，完成额外 +1 分
- 🧮 **积分倍率**：基础分 × 象限倍率（1.5x/1.2x/1.0x/0.5x）四舍五入
- 📋 **策略视图**：一键生成象限任务分析与行动建议
- 🏆 **段位体系**：总积分只增不减，六段位升级，全屏彩带庆祝动画
- 🎁 **奖励兑换**：可用积分兑换现实奖励，可自定义，含每日上限校验
- 🛡️ **防摆烂机制**：连续打卡、免罚卡、周日自动复盘、逾期标红
- 📊 **数据看板**：段位、积分、进度条、今日完成、连续天数、待办/逾期
- 🔊 **交互反馈**：完成 🎉 粒子 + 合成音效、升段庆祝、错误提示、Toast
- 💾 **数据管理**：localStorage 自动保存 + 导出 / 导入 / 清空

## 🚀 快速开始

**方式一（最简单）**：直接双击 `自律RPG.html`，用浏览器打开即可。

**方式二（推荐，体验更稳定）**：在项目目录起一个本地静态服务：

```bash
# Python
python -m http.server 8080

# 或 Node
npx serve .
```

然后浏览器访问 `http://localhost:8080/自律RPG.html`。

> 首次打开任务清单为空，点击右上角「➕ 新任务」开始写自己的任务。

## 🗂️ 四象限（核心功能）

每个任务都有两个维度：**重要性**（重要 / 不重要）和 **紧急性**（紧急 / 不紧急），据此自动归类到四个象限。

| 象限 | 标签 | 背景色 | 边框色 | 积分倍率 |
|---|:---:|:---:|:---:|:---:|
| 🔴 重要且紧急 | 立刻行动🔴 | `#1a0a0a` | `#ff4757` | **1.5x** |
| 🟡 重要不紧急 | 长期投资🟡 | `#0a0f0a` | `#2ed573` | **1.2x** |
| 🟠 紧急不重要 | 快速处理🟠 | `#1a0e00` | `#ffa502` | **1.0x** |
| 🟢 不重要不紧急 | 尽量少做🟢 | `#0a0a0f` | `#a4b0be` | **0.5x** |

- 每个象限为深色底 + 2px 实线强调色边框 + 左上角标签，悬停时边框发光。
- 象限内任务按截止日期升序排列，**逾期任务置顶标红**。
- 移动端（≤560px）四象限自动纵向单列排列。

> 新增任务时默认「重要不紧急」，可在弹窗中修改重要性与紧急性。

## 🗂️ 任务体系

| 类型 | 图标 | 基础得分 | 惩罚 | 说明 |
|---|---|:---:|---:|---|
| 日常习惯 | 🔁 | **+1** | 无 | 每天可做的小事（如喝水、早起）；连续 7 天额外 +3；未完成不扣分；每日自动重置 |
| 固定日程 | 📅 | **+2** | 逾期 -1 | 有截止日期（如交报告）；逾期未完成扣 1 分，可用免罚卡抵消 |
| 一次性目标 | 🎯 | **+5** | 无 | 大块任务（如完成项目），一次完成 |

- 任务可 **添加 / 编辑 / 删除 / 标记完成**，并可写 **备注描述**，必选 **重要性与紧急性**。
- 每日可标记 **3 个 ⭐ 重点任务**，完成额外 **+1 分**（在倍率计算之后叠加）。
- 日程与目标支持「▶ 开始 / ⏸ 暂停」进入「进行中」状态。

## 🏆 积分与段位体系

### 积分规则

- 完成任务获得积分；**总积分只增不减**，决定段位。
- **可用积分** 与总积分同步增加，但消费（兑换奖励）或逾期扣分时 **只扣可用积分，不影响段位**。
- 实际得分 = `round(基础分 × 象限倍率)` +（重点任务 +1）。
  - 🔴 1.5x · 🟡 1.2x · 🟠 1.0x · 🟢 0.5x，四舍五入取整。

### 实际得分速查

| 类型 \ 象限 | 🔴 1.5x | 🟡 1.2x | 🟠 1.0x | 🟢 0.5x |
|---|:---:|:---:|:---:|:---:|
| 日常习惯（+1） | 2 | 1 | 1 | 1 |
| 固定日程（+2） | 3 | 2 | 2 | 1 |
| 一次性目标（+5） | 8 | 6 | 5 | 3 |

### 段位等级

| 段位 | 图标 | 总积分 | 特权 |
|---|---|:---:|---|
| Lv.1 青铜学徒 | 🥉 | 0–9 | — |
| Lv.2 白银行者 | 🥈 | 10–24 | 解锁奖励兑换 |
| Lv.3 黄金战士 | 🥇 | 25–44 | 获得 1 张免罚卡 |
| Lv.4 铂金大师 | 💎 | 45–69 | 自定义称号权限 |
| Lv.5 钻石领主 | 👑 | 70–99 | 获得 2 张免罚卡 |
| Lv.6 传说自律神 | 🌟 | 100+ | 满级 |

> 升级段位时触发全屏庆祝动画（彩带 + 星星 + 合成音效）。

## 📋 四象限策略视图

四象限页顶部「📋 策略视图」按钮，点击自动统计各象限任务数并生成建议：

- 🔴 重要且紧急 > 3 → 「紧急事务较多，建议优先处理」
- 🟡 重要不紧急 > 5 → 「长期规划任务充足，保持节奏」
- 🔴 = 0 且 🟡 > 0 → 「本周无紧急事务，建议深耕重要长期目标」
- 全部为空 → 「还没有任务，先去添加吧！🚀」

## 🎁 奖励兑换系统

可用积分兑换现实奖励，奖励可自定义增删改。

### 预设奖励

| 奖励 | 所需积分 | 每日上限 |
|---|:---:|:---:|
| 刷短视频 15 分钟 | 3 | 2 次 |
| 打游戏 30 分钟 | 5 | 1 次 |
| 打游戏 1 小时 | 10 | 1 次 |
| 看一部电影 | 15 | 1 次 |
| 点奶茶 / 外卖 | 20 | 1 次 |

- 兑换时自动校验 **积分是否足够** 与 **是否超过每日上限**，不足或超限会给出明确提示。
- 自定义奖励可设置名称、积分、每日上限（0 = 不限）与 emoji 图标。
- 奖励兑换在 **Lv.2 白银行者（10 分）** 后解锁。

## 🛡️ 防摆烂机制

- 🔥 **连续打卡**：连续 7 天每天完成至少 1 个任务，额外 +3 分；中断则连续计数归零。
- 🎫 **免罚卡**：达到黄金战士 +1 张、钻石领主 +2 张，可抵消一次逾期扣分。
- 📝 **周日复盘**：每周日自动弹出本周复盘（完成任务数、获得积分、连续打卡天数）。
- 🔴 **逾期标红**：逾期任务在所在象限中明显红色标记并置顶。

## 💾 数据存储与备份

- 数据保存在浏览器 `localStorage`（键名 `selfDisciplineRPG_v1`）。
- **版本兼容**：键名保持不变，旧版本任务自动迁移为「重要不紧急」，升级不丢数据。

- 建议定期在「设置 → 📤 导出数据」备份为 JSON 文件，换设备用「📥 导入数据」恢复。

## ❓ 说明与取舍

- **逾期扣分时机**：在「完成逾期任务」时触发扣分并弹窗询问是否用免罚卡，而非到期那一刻自动扣分——避免用户隔天打开被「暗扣」，免罚卡使用时机也更自然。如需改为「到期自动扣分」，可调整 `completeTask` 中的逾期逻辑。
- **已完成任务**：可编辑、删除，但不可「撤销完成」——因为总积分只增不减，撤销会破坏积分一致性。
- **四舍五入**：`0.5` 会向上取整为 `1`（例如 🟢 象限的习惯任务基础 1 分 × 0.5 = 0.5 → 1 分），符合「四舍五入」规则。
